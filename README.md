**UmaGarden**

### Espacio de Aprendizaje con Umas | Learning Space with Umas

**Website language / Idioma del sitio: Español (Spanish 🇲🇽)**

> 🇪🇸 **Español:** UmaGarden es una página web educativa e interactiva desarrollada en español e inspirada en *Uma Musume: Pretty Derby*. Su objetivo es combinar el aprendizaje y el entretenimiento mediante información histórica, personajes y minijuegos para niños.

> 🇬🇧 **English:** UmaGarden is an educational and interactive fan website inspired by *Uma Musume: Pretty Derby*. The website is developed primarily in **Spanish**, and its purpose is to combine learning and entertainment through historical information, characters, and interactive minigames for children.

## Características | Features

**Inicio / Home:** Jardín con personajes animados / Garden with animated characters.
**Personajes / Characters:** Información y comparaciones con caballos de carreras reales / Information and comparisons with real-life racehorses.
**Galería / Gallery:** Personajes y datos históricos / Characters and historical facts.
**Música / Music:** Reproductor interactivo mediante YouTube / Interactive YouTube music player.
**Juegos / Games:** Cinco minijuegos interactivos / Five interactive minigames.
**Acerca de / About:** Créditos e información del proyecto / Credits and project information.

## Tecnologías | Technologies

- HTML5
- CSS3
- JavaScript
- YouTube IFrame Player API
